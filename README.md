# Estudo de interface com React e TypeScript

Protótipo de interface com tela de login e componentes de navegação. O código atual renderiza a tela de login; não representa um sistema corporativo completo.

## Tecnologias

React, TypeScript, Vite, Chakra UI e Framer Motion.

## Executar

```bash
npm ci
npm run dev
```

Para gerar e visualizar a versão de produção:

```bash
npm run build
npm run preview
```

## Estrutura

- `src/App.tsx`: entrada da interface.
- `src/components/Login.tsx`: tela de login.
- `src/components/`: layout, cabeçalho e navegação.
- `src/theme.ts`: tema visual.
